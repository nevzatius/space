# Textures

- `moon-albedo.jpg` — lunar albedo mosaic (NASA Clementine mission data), sourced from
  the three.js project's public example assets
  (`examples/textures/planets/moon_1024.jpg` in https://github.com/mrdoob/three.js).
  Public domain (US federal government work); redistributed here unmodified.

- `moon-albedo-hires.jpg` — higher-resolution (2048×1024) lunar color map used when the
  "Aya Yaklaş" close-orbit camera mode is active, sourced from Solar System Scope
  (https://www.solarsystemscope.com/textures/, `download/2k_moon.jpg`). Licensed under
  CC BY 4.0 — attribution: Solar System Scope (solarsystemscope.com), redistributed
  unmodified.
